# 世界历史地图 Implementation Plan

**Goal:** 创建中文交互式世界历史地图，探索 1900—2026 年的国界与重大事件。

**Architecture:** Vue 3 单页应用，CShapes 2.0 本地 GeoJSON，按有效日期过滤地图要素。事件日期独立于边界记录，政体更替不等同于国家消失。D3 只负责地理投影和路径，Vue 管理交互。超出数据范围时展示最后已知底图，并醒目标记缺口。

**Tech Stack:** Vue 3 Composition API、TypeScript、Vite、d3-geo、pnpm、Vitest、Playwright、ESLint。

## 设计

- 推荐：交互地图 + 年份时间轴 + 历史事件；兼顾探索和具体日期。
- 备选：故事式专题，内容聚焦但探索较弱；全量历史考证数据库，需大量资料工作。
- 风格：暖白纸张、深绿文字、柔和彩色政治地图，地图占主视觉。
- 左侧为专题与国家检索，中间为可缩放拖动地图，右侧事件卡片，底部为时间轴。
- 默认 1991 年苏联解体主题。事件支持发生前、发生后；年份常规模式按年末。
- 2020—2026 显示最近数据年份说明，不伪造完整覆盖。
- 数据包含属地，图中要素数不作为主权国家总数。
- 加载失败可重试；检索无结果有提示；移动端改为纵向布局；键盘可操作表单和时间轴。

## 实施步骤

1. 配置工程与验证工具；获取 CShapes 数据及许可，保留来源与日期口径。
2. 为事件前后日期、有效区间、超出覆盖范围、年份输入边界编写测试，先运行确认失败。
3. 实现日期筛选、国家中文别名、重点事件目录和关联资料来源。
4. 预处理地图数据，保留几何与有效期；地理投影生成 SVG，实现选择、平移、缩放和搜索。
5. 完成桌面和移动端页面；时间轴、播放、专题和资料说明。
6. 运行 lint、typecheck、单元测试、构建、浏览器测试；验证苏联与德国专题、地图实际变化、2026 提示及移动端。

## 验收与限制

目标是可运行的第一版，不宣称已考证 127 年所有事件与争议边界。CShapes 是特定研究口径，需保留数据说明和 CC BY-NC-SA 4.0 许可。后续 2020—2026 需要补充有来源且许可证兼容的边界变更。

## 用户偏好更新

用户选择优先完整考证的精确历史地图。取消超出覆盖范围时沿用底图的方案，2020—2026直接留空。新增按日检索、记录来源与几何版本、未复核状态、完整核查台账和来源限制报告。现阶段所有边界均为资料导入，不能标记已独立考证。保留原始坐标精度，不做取整压缩。
